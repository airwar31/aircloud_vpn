# Мониторинг устройств VPN

## Описание

Система автоматически отслеживает количество подключенных устройств для каждого VPN ключа и отправляет уведомления пользователям при превышении лимита.

## Как работает

1. **Мониторинг подключений**: Система каждые 5 минут проверяет активные подключения через Xray API
2. **Проверка лимитов**: Сравнивает количество активных устройств с лимитом по тарифу
3. **Уведомления**: Отправляет предупреждения в Telegram при превышении лимита

## Лимиты по тарифам

- **1 месяц**: 1 устройство
- **3 месяца**: 2 устройства  
- **6 месяцев**: 3 устройства
- **1 год**: 5 устройств

## Уведомления

При превышении лимита пользователь получает сообщение:

```
⚠️ Превышен лимит устройств!

🔑 Ключ: user_example_1234
📱 Подключено: 3 устройств
✅ Разрешено: 2 устройств

❗ Отключите 1 лишних устройств, иначе соединение может быть заблокировано.

💡 Для отключения устройства просто выключите VPN на ненужном устройстве.
```

## Настройка

### Автоматический запуск

Мониторинг запускается автоматически через Docker:

```bash
docker-compose up -d device-monitor
```

### Ручной запуск

```bash
python start_monitor.py
```

## Логи

Все события мониторинга записываются в логи:

- Проверки лимитов
- Отправленные уведомления
- Ошибки подключения к API

## Технические детали

### Файлы системы

- `device_monitor.py` - Основной модуль мониторинга
- `start_monitor.py` - Скрипт запуска
- `Dockerfile.monitor` - Docker образ для мониторинга

### Интеграция с базой данных

Система использует поле `device_limit` в таблице `vpn_keys` для определения лимита устройств для каждого ключа.

### Частота проверок

- Проверка активных подключений: каждые 5 минут
- Интервал между уведомлениями: 30 минут (чтобы не спамить)

## Устранение неполадок

### Мониторинг не работает

1. Проверьте подключение к Xray API
2. Убедитесь, что BOT_TOKEN корректный
3. Проверьте логи контейнера:

```bash
docker logs device-monitor
```

### Неточные данные о подключениях

Система использует API Xray для получения статистики. Если данные неточные, возможно:

1. API недоступен
2. Неправильная конфигурация Xray
3. Проблемы с сетью

## Безопасность

- Уведомления отправляются только владельцам ключей
- Система не блокирует подключения автоматически
- Все данные хранятся локально в базе данных

# VPN Telegram Bot с ЮKassa

Telegram бот для автоматической продажи VPN ключей с интеграцией платежной системы ЮKassa и панели управления X-UI.

## 🚀 Возможности

- ✅ Автоматическая продажа VPN подписок
- 💳 Интеграция с ЮKassa для приема платежей
- 🔐 Автоматическое создание VPN ключей через X-UI API
- 📊 Различные тарифные планы
- 📱 Поддержка протоколов VLESS и VMess
- 🎯 Простой и понятный интерфейс

## 📋 Требования

- Python 3.8+
- X-UI панель управления
- Аккаунт ЮKassa
- Telegram Bot Token

## 🛠 Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd vpn-bot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
```bash
cp .env.example .env
```

Отредактируйте файл `.env`:
```env
# Telegram Bot Token (получить у @BotFather)
BOT_TOKEN=your_telegram_bot_token_here

# ЮKassa настройки (из личного кабинета ЮKassa)
YOOKASSA_SHOP_ID=your_yookassa_shop_id
YOOKASSA_SECRET_KEY=your_yookassa_secret_key

# Xray API настройки
XRAY_API_URL=http://localhost:8080
SERVER_IP=your_server_ip
```

## ⚙️ Настройка

### 1. Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен и добавьте в `.env`
3. Настройте команды бота:
   - `/start` - Главное меню
   - `/help` - Инструкция по подключению

### 2. Настройка ЮKassa

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru)
2. Получите Shop ID и Secret Key
3. Добавьте данные в `.env`

### 3. Настройка Xray

Бот работает с собственным Xray сервером в контейнере.
Никаких дополнительных настроек не требуется.

### 4. Настройка тарифов

Отредактируйте файл `config.py` для изменения тарифных планов:

```python
VPN_PLANS = {
    "1month": {
        "name": "1 месяц",
        "price": 200,        # Цена в рублях
        "days": 30,          # Срок действия в днях
        "traffic": 100       # Трафик в ГБ
    },
    # ... другие планы
}
```

## 🚀 Запуск

### Docker (рекомендуется)
```bash
chmod +x start.sh
./start.sh
```

### Обычный запуск
```bash
python bot.py
```

## 📱 Использование

1. Пользователь запускает бота командой `/start`
2. Выбирает тарифный план
3. Оплачивает через ЮKassa
4. Получает VPN конфигурацию
5. Подключается по инструкции `/help`

## 🐛 Решение проблем

### Ошибка подключения к Xray
- Проверьте статус контейнера: `docker-compose ps`
- Проверьте логи: `docker-compose logs xray-api`
- Убедитесь, что порт 8080 доступен

### Ошибка создания платежа
- Проверьте правильность Shop ID и Secret Key
- Убедитесь, что аккаунт ЮKassa активен
- Проверьте лимиты и настройки магазина

### Бот не отвечает
- Проверьте правильность Bot Token
- Убедитесь, что бот запущен
- Проверьте логи на наличие ошибок

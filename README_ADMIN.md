# 🔧 Админ панель VPN бота

Отдельная админ панель для управления VPN ботом.

## 🚀 Функции

- 📢 **Рассылка сообщений** всем пользователям
- 💰 **Изменение цен** на тарифы
- 🎁 **Подарки подписок** пользователям
- 📊 **Статистика** бота и продаж

## ⚙️ Настройка

1. **Добавьте свой Telegram ID в админы:**
```python
# В файле config.py
ADMIN_IDS = [123456789, 987654321]  # Ваши Telegram ID
```

2. **Узнайте свой Telegram ID:**
   - Напишите боту @userinfobot
   - Или используйте @getmyid_bot

## 🚀 Запуск

```bash
# Запуск админ панели
python run_admin.py
```

## 📱 Использование

1. **Запустите админ панель**
2. **Отправьте команду `/admin` боту**
3. **Выберите нужное действие:**

### 📢 Рассылка
- Нажмите "Рассылка"
- Отправьте сообщение для рассылки
- Бот разошлет его всем пользователям

### 💰 Изменение цен
- Нажмите "Цены"
- Выберите тариф
- Введите новую цену

### 🎁 Подарок подписки
- Нажмите "Подарить подписку"
- Введите username (без @) или Telegram ID
- Введите количество дней

### 📊 Статистика
- Показывает общую статистику бота
- Количество пользователей, заказов, выручку
- Реферальную статистику

## 🔒 Безопасность

- Только пользователи из `ADMIN_IDS` имеют доступ
- Все действия логируются
- Рассылка имеет защиту от лимитов Telegram

## 📝 Примеры

## 🐛 Решение проблем

### Нет доступа к админ панели
- Проверьте, что ваш ID добавлен в `ADMIN_IDS`
- Перезапустите админ панель

### Пользователь не найден при подарке
- Убедитесь, что пользователь запускал бота
- Проверьте правильность username/ID

### Ошибка рассылки
- Проверьте токен бота
- Убедитесь в стабильности интернета
